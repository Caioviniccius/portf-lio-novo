Cardoso Exclusive — Loja de Moda Masculina

Loja virtual + painel administrativo

React JavaScript Supabase

Catálogo online para uma loja de moda masculina, relógios, perfumes e acessórios, feito para o cliente escolher e pedir sozinho e para o dono gerenciar tudo sem depender de ninguém.

Principais recursos

  • Busca e filtros por categoria, tamanho e cor
  • Carrinho com pedido enviado direto para o WhatsApp
  • Painel para cadastrar produtos, fotos, estoque e categorias
  • Layout pensado primeiro para o celular

O que explorar

Navegue pelo catálogo, filtre por tamanho ou cor e monte um carrinho. A versão publicada usa produtos de exemplo e permite abrir o painel administrativo.

Ponto Mix — Hamburgueria Artesanal

Cardápio digital com pedidos

HTML5 CSS3 JavaScript

Site de uma hamburgueria artesanal para o cliente ver o cardápio completo e fazer o pedido pelo celular.

Principais recursos

  • Cardápio com mais de 90 produtos (hambúrgueres, combos, pizzas, pastéis, bebidas e sobremesas)
  • Personalização do produto com adicionais
  • Carrinho que mantém os itens salvos
  • Finalização em 3 etapas com o pedido enviado para o WhatsApp

O que explorar

Escolha um hambúrguer, adicione extras e siga até a finalização para ver como o pedido é montado.
