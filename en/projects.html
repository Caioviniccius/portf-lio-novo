Cardoso Exclusive — Men's Fashion Store

Online store + admin dashboard

React JavaScript Supabase

An online catalog for a men's fashion store selling clothing, watches, fragrances and accessories. Customers can browse and order on their own, and the owner can manage the catalog without outside help.

Key features

  • Product search with category, size and color filters
  • Cart that sends the order straight to WhatsApp
  • Admin dashboard to manage products, photos, stock and categories
  • Mobile-first layout

What to explore

Browse the catalog, filter by size or color and add items to the cart. The live version runs on sample products and includes access to the admin dashboard.
